autointent.metrics.scoring_hit_rate
===================================

.. py:function:: autointent.metrics.scoring_hit_rate(labels, scores)

   Calculate hit rate for multilabel classification.

   Hit rate measures the fraction of cases where the top-ranked label is in the set
   of true labels for the instance.

   .. math::

       \text{Hit Rate} = \frac{1}{N} \sum_{i=1}^N \mathbb{1}(y_{\text{top},i} \in y_{\text{true},i})

   :param labels: Ground truth labels for each sample.
   :param scores: For each sample, scores for each of n_classes classes.

   :returns: Hit rate score.
