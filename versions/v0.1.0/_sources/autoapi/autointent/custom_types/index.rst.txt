Package Contents
----------------

.. py:data:: FloatFromZeroToOne

   Float value between 0 and 1, inclusive.

.. py:type:: LabelType
   :canonical: SimpleLabel | MultiLabel


   Type alias for label representation

   - `int`: For single-label classification.
   - `list[int]`: For multi-label classification.

.. py:data:: LabelWithOOS

   Any label that autointent modules can handle.

.. py:data:: ListOfGenericLabels

   List of labels that AutoIntent modules can handle.

.. py:data:: ListOfLabels

   List of labels without OOS-samples that AutoIntent modules can handle.

.. py:data:: ListOfLabelsWithOOS

   List of labels with OOS-samples that AutoIntent modules can handle.

.. py:data:: MultiLabel

   List label for multi-label classification problems.

.. py:data:: MultiLabelWithOOS

   List label for multi-label classification problems with OOS samples.

.. py:data:: SamplerType

   Hyperparameter tuning strategies:

   - `brute`: :py:class:`optuna.samplers.BruteForceSampler`
   - `tpe`: :py:class:`optuna.samplers.TPESampler`
   - `random`: :py:class:`optuna.samplers.RandomSampler`

.. py:data:: SearchSpacePreset

   Some presets that our library supports from lightest to heaviest:

   - `light_extra`: just like `light` but tuned with :py:class:`optuna.samplers.RandomSampler`
   - `light`: only light-weight modules tuned with :py:class:`optuna.samplers.TPESampler`
   - `light_moderate`: just like `light` but tuned with :py:class:`optuna.samplers.BruteForceSampler`
   - `heavy_moderate`: just like `heavy` but tuned with :py:class:`optuna.samplers.RandomSampler`
   - `light`: light-weight modules accompanied with heavy-weight ones tuned with :py:class:`optuna.samplers.TPESampler`
   - `heavy_extra`: just like `light` but tuned with :py:class:`optuna.samplers.BruteForceSampler`

.. py:data:: SearchSpaceValidationMode

   Behavior when meet a data-incompatible module in search space:

   - `raise`: raise an error
   - `warning`: warn user
   - `filter`: drop incompatible modules from search space

.. py:data:: SimpleLabel

   Integer label for single-label classification problems.

.. py:data:: SimpleLabelWithOOS

   Integer label for single-label classification problems with OOS samples.

.. py:data:: ValidationScheme

   Validation scheme used in hyperparameter tuning:

   - `ho`: hold-out validation
   - `cv`: cross-validation

.. py:data:: WeightType

   Represents weight calculation methods

   - "uniform": Equal weight for all elements.
   - "distance": Weights based on distance.
   - "closest": Prioritizes closest elements.
