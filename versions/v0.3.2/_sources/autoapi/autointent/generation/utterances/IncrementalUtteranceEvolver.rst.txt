autointent.generation.utterances.IncrementalUtteranceEvolver
============================================================

.. py:class:: autointent.generation.utterances.IncrementalUtteranceEvolver(generator, prompt_makers, seed = 0, async_mode = False, search_space = None)

   Bases: :py:obj:`autointent.generation.utterances._evolution.evolver.UtteranceEvolver`


   Incremental evolutionary strategy to augmenting utterances.

   This method adds LLM-generated training samples until the quality
   of linear classification on resulting dataset stops rising.

   :param generator: Generator instance for generating utterances.
   :param prompt_makers: List of prompt makers for generating prompts.
   :param seed: Random seed for reproducibility.
   :param async_mode: Whether to use asynchronous mode for generation.
   :param search_space: Search space for the pipeline optimizer.


   .. py:attribute:: search_space


   .. py:method:: augment(dataset, split_name = Split.TRAIN, n_evolutions = 1, update_split = True, batch_size = 4, sequential = False)

      Add LLM-generated samples to some split of dataset.

      :param dataset: Dataset object.
      :param split_name: Dataset split (default is TRAIN).
      :param n_evolutions: Number of evolutions to perform.
      :param update_split: Whether to update the dataset split with the new samples.
      :param batch_size: Batch size for augmentation.
      :param sequential: Whether to perform augmentations sequentially.
