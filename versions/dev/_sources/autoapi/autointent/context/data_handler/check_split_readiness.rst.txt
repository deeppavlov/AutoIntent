autointent.context.data_handler.check_split_readiness
=====================================================

.. py:function:: autointent.context.data_handler.check_split_readiness(dataset, split, config, allow_oos_in_train = None)

   Check whether the dataset has enough samples per class for autointent pipeline.

   :param dataset: The dataset to check (e.g. the same passed to :func:`split_dataset`).
   :param split: The split name to check (e.g. ``Split.TRAIN``).
   :param config: data config
   :param allow_oos_in_train: Same as in :func:`split_dataset`. If the split contains OOS samples
                              and this is ``None``, this function raises ``ValueError`` (mirrors splitting behavior).
