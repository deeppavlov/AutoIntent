autointent.modules.scoring.GCNScorer
====================================

.. py:class:: autointent.modules.scoring.GCNScorer(embedder_config = None, label_embedder_config = None, gcn_hidden_dims = None, p_reweight = 0.2, tau_threshold = 0.4, num_train_epochs = 10, batch_size = 16, learning_rate = 0.001, seed = 42, device = None, early_stopping_config = None)

   Bases: :py:obj:`autointent.modules.scoring._torch.base_scorer.BaseTorchTrainerScorer`


   Graph Convolutional Network (GCN) scorer for intent classification.

   This module uses a GCN to model label correlations for multi-label text
   classification. It leverages embeddings for both utterances and labels
   (descriptions/names) to learn a classifier for each label.

   :param embedder_config: Config for utterance embedder.
   :param label_embedder_config: Config for label description embedder.
   :param gcn_hidden_dims: List of hidden dimensions for GCN layers.
   :param p_reweight: Reweighting parameter for the correlation matrix.
   :param tau_threshold: Threshold for creating the adjacency matrix.
   :param num_train_epochs: Number of training epochs.
   :param batch_size: Batch size for training.
   :param learning_rate: Learning rate for the optimizer.
   :param seed: Random seed for reproducibility.
   :param device: Device to train on ('cpu', 'cuda', etc.).
   :param early_stopping_config: Configuration for early stopping.

   Reference:
       Chen, Z. M., Wei, X. S., Wang, P., & Guo, Y. (2019).
       Multi-Label Image Recognition with Graph Convolutional Networks.
       arXiv preprint arXiv:1904.03582.
