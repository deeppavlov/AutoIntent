autointent.metrics.scoring.scoring_recall
=========================================

.. py:function:: autointent.metrics.scoring.scoring_recall(labels, scores)

   Calculate recall for multiclass and multilabel classification.

   Uses decision_recall to evaluate decisions.

   :param labels: Ground truth labels for each sample.
   :param scores: For each sample, scores for each of n_classes classes.

   :returns: Recall score.
