autointent.configs.LoggingConfig
================================

.. py:class:: autointent.configs.LoggingConfig(/, **data)

   Bases: :py:obj:`pydantic.BaseModel`


   Configuration for the logging.


   .. py:attribute:: model_config

      Configuration for the model, should be a dictionary conforming to [`ConfigDict`][pydantic.config.ConfigDict].


   .. py:attribute:: project_dir
      :type:  pathlib.Path | str | None
      :value: None


      Path to the directory with different runs.


   .. py:attribute:: run_name
      :type:  str | None
      :value: None


      Name of the run. If None, a random name will be generated.
      To get run_name better use :py:meth:`autointent.configs.LoggingConfig.get_run_name`.


   .. py:attribute:: dump_modules
      :type:  bool
      :value: None


      Whether to dump the modules or not


   .. py:attribute:: clear_ram
      :type:  bool
      :value: None


      Whether to clear the RAM after dumping the modules


   .. py:attribute:: report_to
      :type:  list[autointent._callbacks.REPORTERS_NAMES] | None
      :value: None



   .. py:attribute:: log_interval_time
      :type:  float
      :value: None


      List of callbacks to report to. If None, no callbacks will be used


   .. py:property:: dirpath
      :type: pathlib.Path


      Path to the directory where the logs will be saved.


   .. py:property:: dump_dir
      :type: pathlib.Path


      Path to the directory where the modules will be dumped.


   .. py:method:: get_run_name()

      Return name of the run.

      Use this method instead of direct adressing to :py:attr:`autointent.configs.LoggingConfig.run_name`.



   .. py:method:: validate_report_to(value)
      :classmethod:


      Validate the `report_to` field to ensure it is either 'none' or a list of valid reporter names.
