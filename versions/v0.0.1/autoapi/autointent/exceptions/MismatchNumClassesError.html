autointent.exceptions.MismatchNumClassesError#

exception autointent.exceptions.MismatchNumClassesError(message=None)#

Bases: Exception

Exception raised when the data contains an incompatible number of classes.

This error indicates that the number of classes in the input data does not match the expected number of classes for the module.

Parameters:

message (str | None) – Error message, defaults to a standard class incompatibility message

message = "Provided scores number don't match with number of classes which module was trained on."#
