autointent.generation.intents.generate_descriptions
===================================================

.. py:function:: autointent.generation.intents.generate_descriptions(dataset, client, prompt = None)

   Add LLM-generated text descriptions to dataset's intents.

   :param dataset: Dataset containing utterances and intents needing descriptions.
   :param client: OpenAI client for generating descriptions.
   :param prompt: Template for model prompt with placeholders for intent_name,
                  user_utterances, and regex_patterns.

   See :ref:`intent_description_generation` tutorial.
