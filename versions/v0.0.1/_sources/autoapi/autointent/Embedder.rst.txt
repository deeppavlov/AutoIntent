autointent.Embedder
===================

.. py:class:: autointent.Embedder(embedder_config)

   A wrapper for managing embedding models using :py:class:`sentence_transformers.SentenceTransformer`.

   This class handles initialization, saving, loading, and clearing of
   embedding models, as well as calculating embeddings for input texts.


   .. py:attribute:: embedding_model
      :type:  sentence_transformers.SentenceTransformer


   .. py:attribute:: config


   .. py:method:: clear_ram()

      Move the embedding model to CPU and delete it from memory.



   .. py:method:: delete()

      Delete the embedding model and its associated directory.



   .. py:method:: dump(path)

      Save the embedding model and metadata to disk.

      :param path: Path to the directory where the model will be saved.



   .. py:method:: load(path, override_config = None)
      :classmethod:


      Load the embedding model and metadata from disk.

      :param path: Path to the directory where the model is stored.
      :param override_config: one can override presaved settings



   .. py:method:: embed(utterances, task_type = None)

      Calculate embeddings for a list of utterances.

      :param utterances: List of input texts to calculate embeddings for.
      :param task_type: Type of task for which embeddings are calculated.

      :returns: A numpy array of embeddings.



   .. py:method:: similarity(embeddings1, embeddings2)

      Calculate similarity between two sets of embeddings.

      :param embeddings1: First set of embeddings (size n).
      :param embeddings2: Second set of embeddings (size m).

      :returns: A numpy array of similarities (size n x m).
