autointent.exceptions.WrongClassificationError
==============================================

.. py:exception:: autointent.exceptions.WrongClassificationError(message = 'Multiclass module is called on multilabel data or vice-versa')

   Bases: :py:obj:`Exception`


   Exception raised when a classification module is used with incompatible data.

   This error typically occurs when a multiclass module is called on multilabel data
   or vice versa.

   :param message: Error message, defaults to a standard incompatibility message


   .. py:attribute:: message
      :value: 'Multiclass module is called on multilabel data or vice-versa'
