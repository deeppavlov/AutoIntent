autointent.metrics.scoring.scoring_precision
============================================

.. py:function:: autointent.metrics.scoring.scoring_precision(labels, scores)

   Calculate precision for multiclass and multilabel classification.

   Uses decision_precision to evaluate decisions.

   :param labels: Ground truth labels for each sample.
   :param scores: For each sample, scores for each of n_classes classes.

   :returns: Precision score.
