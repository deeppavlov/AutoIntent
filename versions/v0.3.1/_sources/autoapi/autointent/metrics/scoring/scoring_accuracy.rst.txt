autointent.metrics.scoring.scoring_accuracy
===========================================

.. py:function:: autointent.metrics.scoring.scoring_accuracy(labels, scores)

   Calculate accuracy for multiclass and multilabel classification.

   Uses decision_accuracy to evaluate decisions.

   :param labels: Ground truth labels for each utterance.
   :param scores: For each utterance, scores for each of n_classes classes.

   :returns: Classification accuracy score.
